# Feature-Rich, Data-Private: A Sparse Learning Framework for the High-Dimensional Newsvendor
This directory contains the R code and supporting materials required to reproduce the numerical results reported in the paper `Feature-Rich, Data-Private: A Sparse Learning
Framework for the High-Dimensional Newsvendor`. This paper develops a privacy-preserving learning method for high-dimensional newsvendor problems, enabling firms to extract useful demand information from large feature sets while protecting sensitive data.

## Directory Structure

```text
Replication Package/
├── data/ 
├── results/ 
├── scripts/
├── src/ 
├── LICENSE  
└── README.md
```


## Contents

- `data/raw/README.md`: instructions for obtaining and placing the original
  Corporación Favorita data.
- `data/processed/`: directory for the processed data generated from the
  original Corporación Favorita files and used in the empirical analysis.
- `results/figure_data/`: intermediate numerical results used by the plotting
  scripts.
- `results/figures/`: final figures reported in the paper.
- `results/tables/`: numerical results reported in the tables.
- `scripts/figures/`: R scripts for producing the reported figures.
- `scripts/real_data/`: R scripts for preparing the real data and reproducing
  the empirical analysis.
- `scripts/simulations/`: R scripts for reproducing the simulation studies.
- `src/`: R functions implementing the proposed and competing methods.


## Software Requirements

All computations are implemented in R. Scripts run on the Windows computer were
tested using R version 4.4.3, while the computationally intensive simulation
scripts run on the Linux server were tested using R version 4.5.2.

A complete list of the required R packages and their tested versions is
provided in `scripts/README.md`.


## External Data

The empirical analysis uses data from the Kaggle competition
“Corporación Favorita Grocery Sales Forecasting”.

The original competition files are not redistributed in this package.
Download and file-placement instructions are provided in `data/raw/README.md`.
 


## Reproducing the Real-Data Analysis

Follow the data download instructions in `data/raw/README.md`. After placing
the required original files in `data/raw/`, run:

```bash
Rscript scripts/real_data/prepare_real_data.R
```

This script generates `data/processed/processed_data.rds`. Then run:

```bash
Rscript scripts/real_data/main_sec6_real_data.R
Rscript scripts/real_data/supp_NN_real_data.R
```

## Running the Scripts

All scripts must be run from the root directory of the replication package,
i.e., the directory containing `README.md`, `data/`, `results/`, `scripts/`,
and `src/`. 


## Computational Environment

The following computationally intensive simulation scripts were run on a
Linux server equipped with 192 CPU cores and 1.4 TB of RAM:

- `scripts/simulations/main_sec5_example1.R`
- `scripts/simulations/main_sec5_example2.R`
- `scripts/simulations/main_sec5_example3.R`
- `scripts/simulations/main_sec5_example4.R`
- `scripts/simulations/supp_grid.R`
- `scripts/simulations/supp_LDP.R`
- `scripts/simulations/supp_NN_np.R`
- `scripts/simulations/supp_NN_priv.R`



These scripts were executed in parallel using 167 CPU cores, and the observed
memory usage did not exceed 300 GB.

All other simulation experiments and real-data analyses were conducted on a
Windows computer equipped with an Intel(R) Core(TM) i7-14700F CPU at 2.10 GHz
and 32 GB of RAM.

Approximate running times for the individual scripts are provided in
`scripts/README.md`.
